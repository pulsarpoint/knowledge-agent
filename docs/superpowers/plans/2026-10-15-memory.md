# Memory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A shared, per-project memory that agents save to and search (name, metadata, content; full-text + embedding
search), with history, `memory.*` events, and an Administration → Memory page for people.

**Architecture:** admin-api owns two tables (`ka.memories`, `ka.memory_versions`, migration 0111). `memory/store.py`
does every write in one transaction (row, history, event); `memory/search.py` ranks full text and vector distance by
reciprocal rank; `memory/embedding.py` embeds with the project's RAG embedding model through the embedding code moved
to `knowledge_llm.embeddings`. Four `@tool` functions in `capabilities/memory.py` and a REST API in `memory/api.py`
use the store; the UI is `features/memory/`.

**Tech Stack:** Python 3.12+, FastAPI, psycopg 3, PostgreSQL 17 + pgvector, pydantic, pytest; React Router 7,
TypeScript, Vitest + Testing Library, shadcn/ui components.

**Spec:** `docs/superpowers/specs/2026-10-15-memory-design.md`

## Global Constraints

- Migration number **0111** (`db/migrations/0111_memory.up.sql` / `.down.sql`). Check `ls db/migrations | tail -2` on
  main before merging; another session may have taken it.
- Name rule: `^[a-z0-9][a-z0-9._/-]{0,199}$`. Metadata: at most 20 keys, keys `^[a-z][a-z0-9_]{0,63}$`, values
  strings of 1–500 characters. Content 1–20,000 characters, not only whitespace. No NUL characters anywhere.
- Search: reciprocal rank `1 / (60 + position + 1)`, each ranking up to `(offset + limit) * 3` rows; `limit` 1–50
  (tool default 10, UI 25); ties by `updated_at DESC, id`.
- Tool search replies cut content at **2,000** characters, ending `… (call get_memory for the full entry)`.
- Events: `memory.saved`, `memory.updated`, `memory.restored`, `memory.deleted`; `source='memory'`;
  `source_id` = memory id; `subject` = name; payload `{memory_id, name, metadata, revision, agent_id, session_id,
  actor}` — never the content; `dedupe_key` = `memory:<id>:<revision>:<type>`.
- Agents cannot delete or rename; people can (UI/API).
- Embedding never fails a save: no model, a disabled model or a failing call → saved with `embedding = NULL`.
- No compatibility shims: stack data is test data.
- Deviation from the spec, on purpose: `GET /api/memories` pages with `next_offset` (as Notifications does) instead
  of a `total`; it also returns `not_embedded` and `embedding_model`, and `GET /api/memories/agents` feeds the agent filter.
- Backend tests: `cd services/admin-api && uv run --frozen pytest -q -p no:warnings`. RAG:
  `cd services/rag && uv run --frozen pytest -q -p no:warnings`. UI: `cd services/admin-ui && pnpm test` and
  `pnpm exec react-router typegen && pnpm exec tsc --noEmit`.
- Known baseline failures (not caused by this work): in a worktree `test_code_graph_sdk` ×3 errors,
  `test_code_graphs_config` end-to-end, `test_code_processing` go-module-root; everywhere `test_deploy` docs command
  and `test_environments` rollback.
- Never `git stash`, never `make`, never touch `.env`/`.local` or the running Docker stack; never `git add`
  `.superpowers` or `node_modules`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.
- Python style: single quotes, 120 columns, `uv run --frozen ruff format <files>` on files you touch.

## Review Focus

1. Two agents saving the same new name at the same moment — the second gets the *exists* reply with the first one's
   entry, never a 500 (pinned in Task 3).
2. A memory embedded with model A, then the RAG embedding model switched to model B (different dimensions) — search
   must not error on `<=>` between vectors of different sizes, and the entry counts as not embedded (Task 4).
3. Metadata values that are not strings (`{"port": 8080}`, `{"x": null}`, nested objects) from the model or the UI —
   refused with the rule, not stored (Task 3).
4. A search query that is only punctuation or stop-like text (`"/"`, `"--"`) — `websearch_to_tsquery` yields an empty
   query; the search returns no full-text hits without an error (Task 4).
5. Restoring a version whose name is now used by another entry — 409 with *exists*, nothing changed (Task 3).

```python
"""Embeddings for any service: one call for a list of texts, and the profile that names which model made a vector
(a vector is only compared with vectors of the same profile). Errors are ModelUnavailable; callers decide what that
means (RAG answers 502, memory saves without a vector)."""

import hashlib
import json
import math

import httpx

from knowledge_llm import ModelUnavailable, RuntimeModel
from knowledge_llm.bedrock_embeddings import embed_bedrock

MAX_RESPONSE = 8_000_000
REQUEST_FAILED = 'Model request failed; check the saved endpoint, model, and credential'
INVALID = 'Embedding response has invalid dimensions, indexes, or values'


def _digest(value: dict) -> str:
    return hashlib.sha256(json.dumps(value, sort_keys=True, separators=(',', ':')).encode()).hexdigest()


def embedding_profile(model: RuntimeModel | None) -> str:
    if model is None:
        return ''
    if model.provider == 'bedrock':
        return _digest(
            {
                'provider': model.provider,
                'region': model.aws_region,
                'model': model.model,
                'version': model.embedding_version,
                'dimensions': model.embedding_dimensions,
                'input_format': 'text-v1',
                'normalize': True,
            }
        )
    return _digest(
        {
            'url': model.base_url.rstrip('/'),
            'model': model.model,
            'version': model.embedding_version,
            'dimensions': model.embedding_dimensions,
            'input_format': 'text-v1',
        }
    )


def _request(url: str, key: str | None, path: str, payload: dict, transport=None) -> dict:
    try:
        with httpx.Client(timeout=60, follow_redirects=False, transport=transport) as client:
            with client.stream(
                'POST', url.rstrip('/') + path, headers={'Authorization': f'Bearer {key}'} if key else {}, json=payload
            ) as response:
                response.raise_for_status()
                data = bytearray()
                for chunk in response.iter_bytes():
                    data.extend(chunk)
                    if len(data) > MAX_RESPONSE:
                        raise ValueError('oversized response')
        return json.loads(data)
    except (httpx.HTTPError, ValueError):
        raise ModelUnavailable(REQUEST_FAILED) from None


def embed(model: RuntimeModel, texts: list[str], transport=None) -> list[list[float]]:
    if model.provider == 'bedrock':
        return embed_bedrock(model, texts, transport)
    result = _request(model.base_url, model.api_key, '/embeddings', {'model': model.model, 'input': texts}, transport)
    try:
        rows = sorted(result['data'], key=lambda row: row['index'])
        if [row['index'] for row in rows] != list(range(len(texts))):
            raise ValueError('wrong indexes')
        vectors = [row['embedding'] for row in rows]
        for vector in vectors:
            if (
                len(vector) != model.embedding_dimensions
                or any(type(v) not in {int, float} or not math.isfinite(v) or abs(v) > 3.4e38 for v in vector)
                or not any(vector)
            ):
                raise ValueError('invalid vector')
        return vectors
    except (KeyError, TypeError, ValueError):
        raise ModelUnavailable(INVALID) from None
```

```sql
BEGIN;
SET search_path = ka, public;

-- 0111: memory. Agents save what they learn under a unique name with metadata for filtering and content found by
-- words (search_vector) and by meaning (embedding, made by the project's RAG embedding model; NULL when it could not
-- be made). Every change keeps the earlier revision in memory_versions and records a memory.* event.
CREATE FUNCTION jsonb_values_text(value jsonb) RETURNS text LANGUAGE sql IMMUTABLE PARALLEL SAFE AS $$
    SELECT coalesce(string_agg(item.value, ' ' ORDER BY item.key), '') FROM jsonb_each_text(value) AS item
$$;

CREATE TABLE memories (
    id                 uuid PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id         uuid NOT NULL REFERENCES projects(id),
    name               text NOT NULL CHECK (name ~ '^[a-z0-9][a-z0-9._/-]{0,199}$'),
    metadata           jsonb NOT NULL DEFAULT '{}' CHECK (jsonb_typeof(metadata) = 'object'),
    content            text NOT NULL CHECK (char_length(content) BETWEEN 1 AND 20000),
    search_vector      tsvector GENERATED ALWAYS AS (to_tsvector('simple',
                           replace(name, '/', ' ') || ' ' || content || ' ' || jsonb_values_text(metadata))) STORED,
    embedding          public.vector,
    embedding_profile  text,
    revision           integer NOT NULL DEFAULT 1 CHECK (revision >= 1),
    created_by_agent   text REFERENCES agents(id) ON DELETE SET NULL,
    updated_by_agent   text REFERENCES agents(id) ON DELETE SET NULL,
    created_by_session uuid,
    updated_by_session uuid,
    created_by_actor   uuid REFERENCES principals(id),
    updated_by_actor   uuid REFERENCES principals(id),
    created_at         timestamptz NOT NULL DEFAULT now(),
    updated_at         timestamptz NOT NULL DEFAULT now(),
    UNIQUE (project_id, name),
    CONSTRAINT memories_embedding_profile CHECK ((embedding IS NULL) = (embedding_profile IS NULL))
);
COMMENT ON COLUMN memories.created_by_session IS 'ka.agent_sessions.id of the run that saved it (no foreign key: the trace outlives the session).';
CREATE INDEX memories_search ON memories USING gin(search_vector);
CREATE INDEX memories_metadata ON memories USING gin(metadata jsonb_path_ops);
CREATE INDEX memories_recent ON memories(project_id, updated_at DESC, id);

CREATE TABLE memory_versions (
    memory_id   uuid NOT NULL REFERENCES memories(id) ON DELETE CASCADE,
    revision    integer NOT NULL,
    name        text NOT NULL,
    metadata    jsonb NOT NULL,
    content     text NOT NULL,
    by_agent    text,
    by_session  uuid,
    by_actor    uuid,
    changed_at  timestamptz NOT NULL,
    PRIMARY KEY (memory_id, revision)
);
COMMENT ON TABLE memory_versions IS 'Earlier revisions of a memory: copied here before each update, restore or delete.';

ALTER TABLE tools
    DROP CONSTRAINT tools_tool_group_check,
    ADD CONSTRAINT tools_tool_group_check
        CHECK (tool_group IN ('code', 'documents', 'servers', 'inventory', 'agents', 'memory'));
ALTER TABLE events
    DROP CONSTRAINT events_source_check,
    ADD CONSTRAINT events_source_check CHECK (source IN ('jira', 'handler', 'manual', 'memory'));

COMMIT;
```

```python
"""The embedding model memory uses: the project's RAG embedding model (RAG Settings), decoded with the process's
credential key. embed_text never raises: no model, a disabled one or a failing call gives no vector, and the entry is
found by its words until it is embedded again."""

import base64
import os
from uuid import UUID

from cryptography.hazmat.primitives.ciphers.aead import AESGCM
from knowledge_llm import ModelUnavailable, RuntimeModel, decode_model
from knowledge_llm import embeddings


def current_model(conn, project_id: UUID) -> RuntimeModel | None:
    row = conn.execute(
        """SELECT m.* FROM ka.rag_workspaces w JOIN ka.llm_models m ON m.id=w.embedding_model_id
        WHERE w.project_id=%s AND m.enabled AND m.api_format='embeddings'""",
        (project_id,),
    ).fetchone()
    if row is None:
        return None
    try:
        cipher = AESGCM(base64.b64decode(os.environ['CREDENTIAL_ENCRYPTION_KEY'], altchars=b'-_', validate=True))
        return decode_model(row, cipher)
    except Exception:  # a missing key or a credential that does not decrypt: treated as no model
        return None


def embed_text(model: RuntimeModel | None, text: str, transport=None) -> tuple[list[float] | None, str | None]:
    if model is None:
        return None, None
    try:
        return embeddings.embed(model, [text], transport)[0], embeddings.embedding_profile(model)
    except ModelUnavailable:
        return None, None
```

```python
"""Memory entries: one row per name in a project. Every change copies the current row to ka.memory_versions first and
records a memory.* event in the same transaction (the caller's connection; the caller commits). Callers embed the
content before calling — no lock is held during the model call — and pass the vector and its profile, or None."""

import json
import re
from dataclasses import dataclass
from typing import Any
from uuid import UUID

import psycopg
from psycopg.types.json import Jsonb

from knowledge_admin.memory.embedding import current_model
from knowledge_llm import ModelUnavailable
from knowledge_llm import embeddings

NAME = re.compile(r'[a-z0-9][a-z0-9._/-]{0,199}')
KEY = re.compile(r'[a-z][a-z0-9_]{0,63}')
MAX_KEYS, MAX_VALUE, MAX_CONTENT, BATCH = 20, 500, 20000, 32
NAME_RULE = 'A name is 1-200 characters of lowercase letters, digits and . _ / -, starting with a letter or digit.'
KEYS_RULE = 'Metadata has at most 20 keys.'
KEY_RULE = 'Metadata key "{key}" must be lowercase letters, digits and _, starting with a letter (at most 64 characters).'
VALUE_RULE = 'Metadata value of "{key}" must be text of 1-500 characters.'
CONTENT_RULE = 'Content must be 1-20,000 characters and not only spaces.'
NUL_RULE = 'Text must not contain NUL characters.'

ENTRY = """SELECT m.id,m.name,m.metadata,m.content,m.revision,m.created_at,m.updated_at,
    m.created_by_agent,ca.name AS created_by_agent_name,m.updated_by_agent,ua.name AS updated_by_agent_name,
    m.updated_by_actor,p.email AS updated_by_email,m.embedding_profile
    FROM ka.memories m LEFT JOIN ka.agents ca ON ca.id=m.created_by_agent
    LEFT JOIN ka.agents ua ON ua.id=m.updated_by_agent LEFT JOIN ka.principals p ON p.id=m.updated_by_actor"""


class Invalid(ValueError):
    pass


class Exists(Exception):
    def __init__(self, entry: dict):
        super().__init__(entry['name'])
        self.entry = entry


class Stale(Exception):
    def __init__(self, entry: dict):
        super().__init__(entry['name'])
        self.entry = entry


class Missing(Exception):
    pass


@dataclass(frozen=True)
class Author:
    agent_id: str | None = None
    session_id: UUID | None = None
    actor_id: UUID | None = None


def validate(name: str, metadata: Any, content: str) -> None:
    if not isinstance(name, str) or NAME.fullmatch(name) is None:
        raise Invalid(NAME_RULE)
    if not isinstance(metadata, dict):
        raise Invalid(KEYS_RULE)
    if len(metadata) > MAX_KEYS:
        raise Invalid(KEYS_RULE)
    for key, value in metadata.items():
        if not isinstance(key, str) or KEY.fullmatch(key) is None:
            raise Invalid(KEY_RULE.format(key=key))
        if not isinstance(value, str) or not 1 <= len(value) <= MAX_VALUE:
            raise Invalid(VALUE_RULE.format(key=key))
        if '\x00' in value:
            raise Invalid(NUL_RULE)
    if not isinstance(content, str) or not content.strip() or len(content) > MAX_CONTENT:
        raise Invalid(CONTENT_RULE)
    if '\x00' in content:
        raise Invalid(NUL_RULE)


def get(conn, project_id: UUID, *, name: str | None = None, memory_id: UUID | None = None) -> dict | None:
    column, value = ('m.name', name) if name is not None else ('m.id', memory_id)
    return conn.execute(f'{ENTRY} WHERE m.project_id=%s AND {column}=%s', (project_id, value)).fetchone()


def versions(conn, memory_id: UUID) -> list[dict]:
    return conn.execute(
        """SELECT v.revision,v.name,v.metadata,v.content,v.by_agent,a.name AS by_agent_name,v.by_actor,
        p.email AS by_email,v.changed_at FROM ka.memory_versions v LEFT JOIN ka.agents a ON a.id=v.by_agent
        LEFT JOIN ka.principals p ON p.id=v.by_actor WHERE v.memory_id=%s ORDER BY v.revision DESC""",
        (memory_id,),
    ).fetchall()


def version(conn, memory_id: UUID, revision: int) -> dict | None:
    return conn.execute(
        'SELECT revision,name,metadata,content FROM ka.memory_versions WHERE memory_id=%s AND revision=%s',
        (memory_id, revision),
    ).fetchone()


def _event(conn, project_id: UUID, kind: str, memory_id: UUID, name: str, metadata: dict, revision: int,
           author: Author) -> None:
    conn.execute(
        """INSERT INTO ka.events(project_id,source,source_id,type,subject,title,payload,dedupe_key,occurred_at)
        VALUES (%s,'memory',%s,%s,%s,'',%s,%s,now())""",
        (
            project_id,
            memory_id,
            kind,
            name,
            Jsonb(
                {
                    'memory_id': str(memory_id),
                    'name': name,
                    'metadata': metadata,
                    'revision': revision,
                    'agent_id': author.agent_id,
                    'session_id': None if author.session_id is None else str(author.session_id),
                    'actor': None if author.actor_id is None else str(author.actor_id),
                }
            ),
            f'memory:{memory_id}:{revision}:{kind}',
        ),
    )


def _vector(vector: list[float] | None) -> str | None:
    return None if vector is None else json.dumps(vector)


def create(conn, project_id: UUID, name: str, metadata: dict, content: str, author: Author,
           vector: list[float] | None, profile: str | None) -> dict:
    validate(name, metadata, content)
    try:
        with conn.transaction():
            memory_id = conn.execute(
                """INSERT INTO ka.memories(project_id,name,metadata,content,embedding,embedding_profile,
                created_by_agent,updated_by_agent,created_by_session,updated_by_session,created_by_actor,updated_by_actor)
                VALUES (%s,%s,%s,%s,%s::public.vector,%s,%s,%s,%s,%s,%s,%s) RETURNING id""",
                (
                    project_id, name, Jsonb(metadata), content, _vector(vector), profile if vector else None,
                    author.agent_id, author.agent_id, author.session_id, author.session_id,
                    author.actor_id, author.actor_id,
                ),
            ).fetchone()['id']
    except psycopg.errors.UniqueViolation:
        raise Exists(get(conn, project_id, name=name)) from None
    _event(conn, project_id, 'memory.saved', memory_id, name, metadata, 1, author)
    return get(conn, project_id, memory_id=memory_id)


def _locked(conn, project_id: UUID, memory_id: UUID) -> dict:
    row = conn.execute(
        'SELECT * FROM ka.memories WHERE id=%s AND project_id=%s FOR UPDATE', (memory_id, project_id)
    ).fetchone()
    if row is None:
        raise Missing()
    return row


def _keep(conn, row: dict) -> None:
    conn.execute(
        """INSERT INTO ka.memory_versions(memory_id,revision,name,metadata,content,by_agent,by_session,by_actor,changed_at)
        VALUES (%s,%s,%s,%s,%s,%s,%s,%s,%s)""",
        (
            row['id'], row['revision'], row['name'], Jsonb(row['metadata']), row['content'],
            row['updated_by_agent'], row['updated_by_session'], row['updated_by_actor'], row['updated_at'],
        ),
    )


def _replace(conn, project_id: UUID, row: dict, kind: str, name: str, metadata: dict, content: str, author: Author,
             vector: list[float] | None, profile: str | None) -> dict:
    validate(name, metadata, content)
    try:
        with conn.transaction():
            _keep(conn, row)
            conn.execute(
                """UPDATE ka.memories SET name=%s,metadata=%s,content=%s,embedding=%s::public.vector,
                embedding_profile=%s,revision=revision+1,updated_by_agent=%s,updated_by_session=%s,
                updated_by_actor=%s,updated_at=now() WHERE id=%s""",
                (
                    name, Jsonb(metadata), content, _vector(vector), profile if vector else None,
                    author.agent_id, author.session_id, author.actor_id, row['id'],
                ),
            )
    except psycopg.errors.UniqueViolation:
        raise Exists(get(conn, project_id, name=name)) from None
    _event(conn, project_id, kind, row['id'], name, metadata, row['revision'] + 1, author)
    return get(conn, project_id, memory_id=row['id'])


def update(conn, project_id: UUID, memory_id: UUID, name: str, metadata: dict, content: str, revision: int,
           author: Author, vector: list[float] | None, profile: str | None) -> dict:
    row = _locked(conn, project_id, memory_id)
    if row['revision'] != revision:
        raise Stale(get(conn, project_id, memory_id=memory_id))
    return _replace(conn, project_id, row, 'memory.updated', name, metadata, content, author, vector, profile)


def restore(conn, project_id: UUID, memory_id: UUID, revision: int, current_revision: int, author: Author,
            vector: list[float] | None, profile: str | None) -> dict:
    row = _locked(conn, project_id, memory_id)
    if row['revision'] != current_revision:
        raise Stale(get(conn, project_id, memory_id=memory_id))
    old = version(conn, memory_id, revision)
    if old is None:
        raise Missing()
    return _replace(
        conn, project_id, row, 'memory.restored', old['name'], old['metadata'], old['content'], author, vector, profile
    )


def delete(conn, project_id: UUID, memory_id: UUID, revision: int, author: Author) -> None:
    row = _locked(conn, project_id, memory_id)
    if row['revision'] != revision:
        raise Stale(get(conn, project_id, memory_id=memory_id))
    conn.execute('DELETE FROM ka.memories WHERE id=%s', (memory_id,))
    _event(conn, project_id, 'memory.deleted', memory_id, row['name'], row['metadata'], row['revision'], author)


def reembed(store, project_id: UUID, transport=None) -> dict:
    """Embed, in batches of 32, every entry without a vector of the current model's profile. Not a change of the entry:
    no new revision, no event; an entry edited meanwhile (revision moved) keeps its own new vector. Raises Missing when
    there is no usable model."""
    with store.connect() as conn:
        model = current_model(conn, project_id)
    if model is None:
        raise Missing()
    profile = embeddings.embedding_profile(model)
    embedded = failed = 0
    tried: list[UUID] = []
    while True:
        with store.connect() as conn:
            rows = conn.execute(
                """SELECT id,content,revision FROM ka.memories WHERE project_id=%s
                AND embedding_profile IS DISTINCT FROM %s AND NOT (id = ANY(%s)) ORDER BY id LIMIT %s""",
                (project_id, profile, tried, BATCH),
            ).fetchall()
        if not rows:
            return {'embedded': embedded, 'failed': failed}
        tried += [row['id'] for row in rows]
        try:
            vectors = embeddings.embed(model, [row['content'] for row in rows], transport)
        except ModelUnavailable:
            failed += len(rows)
            continue
        with store.connect() as conn:
            for row, vector in zip(rows, vectors, strict=True):
                done = conn.execute(
                    """UPDATE ka.memories SET embedding=%s::public.vector,embedding_profile=%s
                    WHERE id=%s AND revision=%s""",
                    (json.dumps(vector), profile, row['id'], row['revision']),
                ).rowcount
                embedded += done
```

  Note: `profile if vector else None` keeps the CHECK `(embedding IS NULL) = (embedding_profile IS NULL)` true.

```python
"""Memory search: full text (websearch_to_tsquery over name, content and metadata values) and vector distance among
entries embedded with the query's profile, merged by reciprocal rank as RAG does. Without a query: the filtered
entries, newest first. Vectors of another profile (another model, maybe other dimensions) are never compared."""

import json
from uuid import UUID

from psycopg.types.json import Jsonb

from knowledge_admin.memory.store import ENTRY

RANK = 60


def _filters(project_id: UUID, metadata: dict | None, agent_id: str | None) -> tuple[str, list]:
    where, values = ['m.project_id=%s'], [project_id]
    if metadata:
        where.append('m.metadata @> %s')
        values.append(Jsonb(metadata))
    if agent_id:
        where.append('(m.created_by_agent=%s OR m.updated_by_agent=%s)')
        values += [agent_id, agent_id]
    return ' AND '.join(where), values


def search(conn, project_id: UUID, *, query: str | None = None, metadata: dict | None = None,
           agent_id: str | None = None, limit: int = 10, offset: int = 0, vector: list[float] | None = None,
           profile: str | None = None) -> list[dict]:
    filters, values = _filters(project_id, metadata, agent_id)
    if not query or not query.strip():
        rows = conn.execute(
            f'{ENTRY} WHERE {filters} ORDER BY m.updated_at DESC, m.id LIMIT %s OFFSET %s', (*values, limit, offset)
        ).fetchall()
        return [{**row, 'score': 0.0} for row in rows]
    depth = (offset + limit) * 3
    rankings = [
        conn.execute(
            f"""SELECT m.id FROM ka.memories m WHERE {filters}
            AND m.search_vector @@ websearch_to_tsquery('simple',%s)
            ORDER BY ts_rank_cd(m.search_vector, websearch_to_tsquery('simple',%s)) DESC, m.updated_at DESC, m.id
            LIMIT %s""",
            (*values, query, query, depth),
        ).fetchall()
    ]
    if vector is not None and profile:
        rankings.append(
            conn.execute(
                f"""SELECT m.id FROM ka.memories m WHERE {filters} AND m.embedding_profile=%s
                ORDER BY m.embedding <=> %s::public.vector, m.updated_at DESC, m.id LIMIT %s""",
                (*values, profile, json.dumps(vector), depth),
            ).fetchall()
        )
    scores: dict[UUID, float] = {}
    for ranking in rankings:
        for position, row in enumerate(ranking):
            scores[row['id']] = scores.get(row['id'], 0.0) + 1 / (RANK + position + 1)
    if not scores:
        return []
    rows = conn.execute(f'{ENTRY} WHERE m.id = ANY(%s)', (list(scores),)).fetchall()
    rows.sort(key=lambda row: (-scores[row['id']], -row['updated_at'].timestamp(), str(row['id'])))
    return [{**row, 'score': scores[row['id']]} for row in rows[offset : offset + limit]]


def not_embedded(conn, project_id: UUID, profile: str | None) -> int:
    """Entries without a vector of `profile` (all of them when there is no model)."""
    return conn.execute(
        'SELECT count(*) AS n FROM ka.memories WHERE project_id=%s AND embedding_profile IS DISTINCT FROM %s',
        (project_id, profile),
    ).fetchone()['n']
```

  The `WHERE … m.embedding_profile=%s` filter is what keeps pgvector from comparing vectors of different dimensions
  (`test_vectors_of_another_profile…`).

```python
"""The memory tools: search_memory, get_memory, save_memory, update_memory. One shared memory per project; each
entry records the agent and session that saved it (config['session_id'] → ka.agent_sessions.agent_id; a run without a
session saves with neither). Saving an existing name is refused with the entry so the agent merges and updates with
the revision it read; agents never delete. Replies are JSON."""

import asyncio
import json
from typing import Annotated, Any
from uuid import UUID

from pydantic import Field

from knowledge_admin.capabilities.inventory import connect, project_of
from knowledge_admin.memory import store as memory
from knowledge_admin.memory.embedding import current_model, embed_text
from knowledge_admin.memory.search import search
from knowledge_admin.tools.registry import tool

PREVIEW = 2000
MORE = '… (call get_memory for the full entry)'
NOT_EMBEDDED = 'Not embedded: found by words only until it is embedded.'
EXISTS = 'An entry with this name exists. Merge your new information into its content and call update_memory with revision {revision}.'
STALE = 'It changed since you read it: merge again and call update_memory with revision {revision}.'
MISSING = 'No entry named {name}; use save_memory.'
NO_AGENT = 'No agent named {name}.'
UNAVAILABLE = 'Memory is unavailable right now.'

Name = Annotated[str, Field(min_length=1, max_length=200, description='The entry name, e.g. payments-api/deploy-steps.')]
Content = Annotated[str, Field(min_length=1, max_length=20000, description='The full text of the entry.')]
Metadata = Annotated[
    dict[str, str],
    Field(description='Text values you will filter by, e.g. {"service": "payments-api", "kind": "runbook"}.'),
]


def _reply(value: dict) -> str:
    return json.dumps(value, ensure_ascii=False, default=str)


def _shown(entry: dict, cut: bool) -> dict:
    content = entry['content']
    if cut and len(content) > PREVIEW:
        content = content[:PREVIEW] + MORE
    return {
        'name': entry['name'],
        'metadata': entry['metadata'],
        'content': content,
        'revision': entry['revision'],
        'saved_by': entry['updated_by_agent_name'] or (None if entry['updated_by_actor'] is None else 'a person'),
        'updated_at': entry['updated_at'].isoformat(),
        'embedded': entry['embedding_profile'] is not None,
    }


def _author(conn, config: dict[str, Any]) -> memory.Author:
    session = config.get('session_id')
    if not session:
        return memory.Author()
    row = conn.execute('SELECT agent_id FROM ka.agent_sessions WHERE id=%s', (session,)).fetchone()
    return memory.Author(agent_id=None if row is None else row['agent_id'], session_id=UUID(str(session)))


def _embedded(config: dict[str, Any], text: str) -> tuple[UUID, list[float] | None, str | None]:
    with connect() as conn:
        project = project_of(conn, config)
        model = current_model(conn, project)
    vector, profile = embed_text(model, text)
    return project, vector, profile


def _guarded(run):
    try:
        return run()
    except memory.Invalid as error:
        return _reply({'refused': str(error)})
    except ValueError:  # the store is not configured in this process
        return _reply({'refused': UNAVAILABLE})


def _search(config, query, metadata, agent, limit) -> str:
    def run():
        with connect() as conn:
            project = project_of(conn, config)
            agent_id = None
            if agent:
                row = conn.execute('SELECT id FROM ka.agents WHERE lower(name)=lower(%s)', (agent,)).fetchone()
                if row is None:
                    return _reply({'refused': NO_AGENT.format(name=agent)})
                agent_id = row['id']
            model = current_model(conn, project) if query and query.strip() else None
        vector, profile = embed_text(model, query) if model else (None, None)
        with connect() as conn:
            rows = search(conn, project, query=query, metadata=metadata or None, agent_id=agent_id, limit=limit,
                          vector=vector, profile=profile)
        return _reply({'results': [_shown(row, cut=True) for row in rows]})

    return _guarded(run)


def _get(config, name) -> str:
    def run():
        with connect() as conn:
            entry = memory.get(conn, project_of(conn, config), name=name)
        if entry is None:
            return _reply({'refused': MISSING.format(name=name)})
        return _reply({'memory': _shown(entry, cut=False)})

    return _guarded(run)


def _save(config, name, content, metadata) -> str:
    def run():
        memory.validate(name, metadata, content)
        project, vector, profile = _embedded(config, content)
        with connect() as conn:
            try:
                entry = memory.create(conn, project, name, metadata, content, _author(conn, config), vector, profile)
            except memory.Exists as exists:
                return _reply({
                    'refused': EXISTS.format(revision=exists.entry['revision']),
                    'memory': _shown(exists.entry, cut=False),
                })
        done = {'saved': {'name': entry['name'], 'revision': 1, 'embedded': vector is not None}}
        return _reply(done if vector is not None else {**done, 'note': NOT_EMBEDDED})

    return _guarded(run)


def _update(config, name, content, metadata, revision) -> str:
    def run():
        memory.validate(name, metadata, content)
        project, vector, profile = _embedded(config, content)
        with connect() as conn:
            current = memory.get(conn, project, name=name)
            if current is None:
                return _reply({'refused': MISSING.format(name=name)})
            try:
                entry = memory.update(conn, project, current['id'], name, metadata, content, revision,
                                      _author(conn, config), vector, profile)
            except memory.Stale as stale:
                return _reply({'refused': STALE.format(revision=stale.entry['revision']),
                               'memory': _shown(stale.entry, cut=False)})
        done = {'updated': {'name': entry['name'], 'revision': entry['revision'], 'embedded': vector is not None}}
        return _reply(done if vector is not None else {**done, 'note': NOT_EMBEDDED})

    return _guarded(run)


@tool
async def search_memory(
    context,
    query: Annotated[str | None, Field(max_length=500, description='Words or a question; omit to list by filters.')] = None,
    metadata: Annotated[dict[str, str] | None, Field(description='Only entries with all these metadata values.')] = None,
    agent: Annotated[str | None, Field(max_length=100, description='Only entries this agent saved (its name).')] = None,
    limit: Annotated[int, Field(ge=1, le=50, description='How many entries, 1-50.')] = 10,
) -> str:
    """Search the shared memory: what any agent saved before. Search before you save, to update an entry instead of duplicating it. Results show each entry's name, metadata, revision, who saved it and its content (long content is cut; read the whole entry with get_memory)."""
    return await asyncio.to_thread(_search, context['config'], query, metadata, agent, limit)


@tool
async def get_memory(context, name: Name) -> str:
    """Read one memory entry in full, with its revision (needed to update it)."""
    return await asyncio.to_thread(_get, context['config'], name)


@tool
async def save_memory(context, name: Name, content: Content, metadata: Metadata | None = None) -> str:
    """Save a new memory entry: one fact or procedure under a stable name (lowercase letters, digits and . _ / -, e.g. payments-api/deploy-steps), with metadata for what you will filter by. If the name exists you get the entry back: merge your information into it and call update_memory."""
    return await asyncio.to_thread(_save, context['config'], name, content, metadata or {})


@tool
async def update_memory(
    context,
    name: Name,
    content: Content,
    metadata: Metadata,
    revision: Annotated[int, Field(ge=1, description='The revision you read with get_memory or search_memory.')],
) -> str:
    """Replace a memory entry's content and metadata with your merged version. Give the revision you read; if someone changed it since, you get the current entry back to merge again. Keep what is still true from the old content."""
    return await asyncio.to_thread(_update, context['config'], name, content, metadata, revision)
```

```python
"""Administration → Memory: search, read (with earlier versions), create, edit, restore, delete and re-embed memory
entries. Changes made here are a person's (the actor), record the same memory.* events as the agent tools and an audit
row. The content is embedded before the transaction; without a model an entry is saved without a vector."""

import json
from functools import partial
from uuid import UUID

from fastapi import APIRouter, HTTPException, Query, Request, Response
from pydantic import BaseModel, ConfigDict, Field

from knowledge_admin.access import request_actor
from knowledge_admin.db import audit as write_audit
from knowledge_admin.db import storage, workspace
from knowledge_admin.memory import store as memory
from knowledge_admin.memory.embedding import current_model, embed_text
from knowledge_admin.memory.search import not_embedded, search
from knowledge_admin.repositories import RepositoryStore
from knowledge_llm import embeddings

PAGE, MAX_PAGE, MAX_OFFSET = 25, 50, 100000
NOT_FOUND = 'Memory entry not found.'
STALE = 'This entry changed since you opened it.'
EXISTS = 'An entry named {name} already exists.'
NO_MODEL = 'Select an embedding model in RAG Settings.'
BAD_METADATA = 'metadata must be a JSON object of text values.'


class Draft(BaseModel):
    model_config = ConfigDict(extra='forbid')
    name: str = Field(max_length=200)
    metadata: dict = Field(default_factory=dict)
    content: str = Field(max_length=20000)


class Edit(Draft):
    revision: int = Field(ge=1)


class Restore(BaseModel):
    model_config = ConfigDict(extra='forbid')
    revision: int = Field(ge=1)
    current_revision: int = Field(ge=1)


def build_api(app: str, store: RepositoryStore | None) -> APIRouter:
    router = APIRouter()
    database = partial(storage, store, 'Memory storage', message='Memory storage is not configured')

    def embedded(text: str) -> tuple[list[float] | None, str | None]:
        db = database()
        with db.connect() as conn:
            model = current_model(conn, db.project(conn, app))
        return embed_text(model, text)

    def author(conn, request: Request) -> memory.Author:
        return memory.Author(actor_id=database().actor(conn, *request_actor(request)))

    def audit(conn, project: UUID, who: memory.Author, action: str, entry_id: UUID, name: str) -> None:
        write_audit(conn, project, who.actor_id, action, 'memory', entry_id, {'name': name})

    @router.get('/memories')
    def list_memories(
        query: str | None = Query(None, max_length=500),
        metadata: str | None = Query(None, max_length=10000),
        agent: str | None = Query(None, max_length=100),
        offset: int = Query(0, ge=0, le=MAX_OFFSET),
        limit: int = Query(PAGE, ge=1, le=MAX_PAGE),
    ) -> dict:
        filters = None
        if metadata:
            try:
                filters = json.loads(metadata)
            except ValueError:
                raise HTTPException(400, BAD_METADATA) from None
            if not isinstance(filters, dict) or not all(isinstance(v, str) for v in filters.values()):
                raise HTTPException(400, BAD_METADATA)
        db = database()
        with db.connect() as conn:
            project = db.project(conn, app)
            model = current_model(conn, project)
        profile = embeddings.embedding_profile(model) if model else None
        vector = embed_text(model, query)[0] if model and query and query.strip() else None
        with db.connect() as conn:
            rows = search(conn, project, query=query, metadata=filters, agent_id=agent, limit=limit + 1,
                          offset=offset, vector=vector, profile=profile)
            missing = not_embedded(conn, project, profile)
        return {
            'memories': rows[:limit],
            'next_offset': offset + limit if len(rows) > limit else None,
            'not_embedded': missing,
            'embedding_model': model is not None,
        }

    @router.get('/memories/agents')
    def agents() -> dict:
        db = database()
        with db.connect() as conn:
            rows = conn.execute(
                """SELECT DISTINCT a.id,a.name FROM ka.memories m JOIN ka.agents a
                ON a.id IN (m.created_by_agent,m.updated_by_agent) WHERE m.project_id=%s ORDER BY a.name,a.id""",
                (db.project(conn, app),),
            ).fetchall()
        return {'agents': rows}

    @router.post('/memories/re-embed')
    def reembed() -> dict:
        db = database()
        with db.connect() as conn:
            project = db.project(conn, app)
        try:
            return memory.reembed(db, project)
        except memory.Missing:
            raise HTTPException(409, NO_MODEL) from None

    @router.get('/memories/{memory_id}')
    def one(memory_id: UUID) -> dict:
        db = database()
        with workspace(db, app) as (conn, project):
            entry = memory.get(conn, project, memory_id=memory_id)
            if entry is None:
                raise HTTPException(404, NOT_FOUND)
            return {'memory': entry, 'versions': memory.versions(conn, memory_id)}

    @router.post('/memories', status_code=201)
    def create(value: Draft, request: Request) -> dict:
        try:
            memory.validate(value.name, value.metadata, value.content)
        except memory.Invalid as error:
            raise HTTPException(400, str(error)) from None
        vector, profile = embedded(value.content)
        db = database()
        with workspace(db, app) as (conn, project):
            who = author(conn, request)
            try:
                entry = memory.create(conn, project, value.name, value.metadata, value.content, who, vector, profile)
            except memory.Exists:
                raise HTTPException(409, EXISTS.format(name=value.name)) from None
            audit(conn, project, who, 'memory.created', entry['id'], entry['name'])
            return {'memory': entry}

    @router.put('/memories/{memory_id}')
    def edit(memory_id: UUID, value: Edit, request: Request) -> dict:
        try:
            memory.validate(value.name, value.metadata, value.content)
        except memory.Invalid as error:
            raise HTTPException(400, str(error)) from None
        vector, profile = embedded(value.content)
        db = database()
        with workspace(db, app) as (conn, project):
            who = author(conn, request)
            try:
                entry = memory.update(conn, project, memory_id, value.name, value.metadata, value.content,
                                      value.revision, who, vector, profile)
            except memory.Missing:
                raise HTTPException(404, NOT_FOUND) from None
            except memory.Stale:
                raise HTTPException(409, STALE) from None
            except memory.Exists:
                raise HTTPException(409, EXISTS.format(name=value.name)) from None
            audit(conn, project, who, 'memory.updated', memory_id, entry['name'])
            return {'memory': entry}

    @router.post('/memories/{memory_id}/restore')
    def restore(memory_id: UUID, value: Restore, request: Request) -> dict:
        db = database()
        with workspace(db, app) as (conn, project):
            old = memory.version(conn, memory_id, value.revision)
        if old is None:
            raise HTTPException(404, NOT_FOUND)
        vector, profile = embedded(old['content'])
        with workspace(db, app) as (conn, project):
            who = author(conn, request)
            try:
                entry = memory.restore(conn, project, memory_id, value.revision, value.current_revision, who,
                                       vector, profile)
            except memory.Missing:
                raise HTTPException(404, NOT_FOUND) from None
            except memory.Stale:
                raise HTTPException(409, STALE) from None
            except memory.Exists:
                raise HTTPException(409, EXISTS.format(name=old['name'])) from None
            audit(conn, project, who, 'memory.restored', memory_id, entry['name'])
            return {'memory': entry}

    @router.delete('/memories/{memory_id}', status_code=204)
    def delete(memory_id: UUID, request: Request, revision: int = Query(ge=1)) -> Response:
        db = database()
        with workspace(db, app) as (conn, project):
            who = author(conn, request)
            entry = memory.get(conn, project, memory_id=memory_id)
            try:
                memory.delete(conn, project, memory_id, revision, who)
            except memory.Missing:
                raise HTTPException(404, NOT_FOUND) from None
            except memory.Stale:
                raise HTTPException(409, STALE) from None
            audit(conn, project, who, 'memory.deleted', memory_id, entry['name'])
        return Response(status_code=204)

    return router
```

  `@router.post('/memories/re-embed')` and `/memories/agents` are declared **before** `/memories/{memory_id}` so they
  are not parsed as ids. If `memory.Stale`/`Exists` raised mid-transaction leaves the connection unusable for the
  audit write, that is fine: those paths raise before `audit`.

```ts
  agent: string;

  content: string;

  next_offset: number | null;
  not_embedded: number;
  embedding_model: boolean;

const json = (body: unknown, method = "POST"): RequestInit => ({
  method,
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(body),
});

export function savedBy(entry: Pick<MemoryEntry, "updated_by_agent_name" | "updated_by_email">): string {
  return entry.updated_by_agent_name ?? entry.updated_by_email ?? "—";
}

export function getMemories(filters: MemoryFilters, offset = 0, signal?: AbortSignal) {
  const query = new URLSearchParams();
  if (filters.query.trim()) query.set("query", filters.query.trim());
  if (Object.keys(filters.metadata).length) query.set("metadata", JSON.stringify(filters.metadata));
  if (filters.agent) query.set("agent", filters.agent);
  if (offset > 0) query.set("offset", String(offset));
  const suffix = query.toString();
  return request<MemoryList>(`/api/memories${suffix ? `?${suffix}` : ""}`, { signal });
}
```
